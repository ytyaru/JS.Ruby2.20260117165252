# Jaml構文

　JamlはJapanese Markup Languageの略で、日本語の文書を意味付けする軽量マークアップ言語である。

　2026年現在、文書作成においては以下のような問題がある。

1. プレーンテキストでは文書の構造を体系化できない
2. HTMLでは複雑・冗長すぎる
3. Markdownでは機能不足
4. MDXでは自力実装が大変すぎる

　そこでJamlを作ることにした。

* jaml/
    * security/                 Unicodeなど各種文脈におけるセキュリティ対策（膨大すぎて全対処不能）
        * unicode/
            * sanitizer.js      U+0000を削除する。不可視文字、ホモグラフ削除。
        * html/
            * sanitizer.js      '<'などのメタ文字を削除。https://cdnjs.com/libraries/dompurify
    * util/                     UnicodeやRegExpの限界により妥協せねばならない（膨大すぎて全対処不能）
        * jaml-control-chars.js Jamlで許可された空白・制御コードのみ（HT,LF,SP,U+3000）
        * invisible-chars.js    Unicodeに存在する不可視文字のみ
        * homograph-chars.js    Unicodeに存在する類似字形視文字のみ
        * japanese-chars.js     日本語圏で使う文字のみ
            * kanji.js
            * odoriji.js        /[\u3005\u303B\u309D\u309E\u30FD\u30FE\u3003\u3031-\u3035]/g

```javascript
const html = Jaml.parse(原稿);
document.body.innerHTML = html;
```

原稿テキストはまず正規化する。Unicodeの正規化をする。これにて仮名に濁音がつく複数パターンを統一できる。

```javascript
String.prototype.normalize('NFC')
```

それに加えて、Jamlとして許可していない文字の削除などをする。例えばCRコードの削除など。

blocks.filter(fen)
