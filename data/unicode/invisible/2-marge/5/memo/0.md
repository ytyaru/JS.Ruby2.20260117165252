# 1. Unicode公式データからの抽出 (unicode.tsv)

Unicode標準のデータベース（UCD: Unicode Character Database）から、一般的に「不可視」とみなされるカテゴリの文字を抽出します。

## 判定基準（採用カテゴリ）

以下の General_Category プロパティを持つ文字を「不可視文字」の候補として抽出します。

* Cc (Control): 制御文字（改行、タブなど）
* Cf (Format): 書式設定文字（ZWJ、BOM、RLOなど）
* Zs (Space Separator): 空白文字（スペース、全角スペースなど）
* Zl (Line Separator): 行区切り
* Zp (Paragraph Separator): 段落区切り
* Mn (Nonspacing Mark): 非前進結合記号（基底文字に重なる不可視の修飾など）

## 情報源

* [UnicodeData.txt][]: カテゴリ情報の主ソース
* [PropList.txt][]: White_Space や Default_Ignorable_Code_Point などの補足プロパティ確認用

[UnicodeData.txt]:https://www.unicode.org/Public/UCD/latest/ucd/UnicodeData.txt
[PropList.txt]:https://www.unicode.org/Public/UCD/latest/ucd/PropList.txt

## 抽出用Pythonコード (extract_unicode_tsv.py)

> 以下のコードを実行することで、最新の UnicodeData.txt をオンラインから取得し、指定カテゴリの文字を unicode.tsv に出力します。

```python
import requests
import unicodedata

def generate_unicode_tsv():
    url = "https://www.unicode.org/Public/UCD/latest/ucd/UnicodeData.txt"
    response = requests.get(url)
    target_categories = {'Cc', 'Cf', 'Zs', 'Zl', 'Zp', 'Mn'}
    
    with open("src/db/unicode.tsv", "w", encoding="utf-8") as f:
        for line in response.text.strip().split('\n'):
            fields = line.split(';')
            code_hex = fields[0]
            category = fields[2]
            
            if category in target_categories:
                f.write(f"{code_hex}\t{category}\n")

if __name__ == "__main__":
    generate_unicode_tsv()
```
