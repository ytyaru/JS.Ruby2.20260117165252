# Unicodeから日本語圏で使う文字だけを抽出したい

```js
\p{Sc=Han}                  CJK統合漢字＋部首＋記号（〇々〃）
\p{Unified_Ideograph}       CJK統合漢字のみ
```

\p{Sc=Han}が拾う記号だけを示す方法はありますか？　それをXとすれば`[\p{Unified_Ideograph}X]+`として正規表現において漢字と記号（漢数字〇や々〃等）を含めることができそうです。


`[\p{Script=Han}--\p{Unified_Ideograph}]`だと部首が含まれてしまいます。部首は除きたいのです。ホモグラフ攻撃されるから。文字クラスとして表現する方法はありませんか？

いや違うって。「\p{Sc=Han}」が拾う記号だけを抽出する文字クラスはないの？


（Script=Han の中から Unified_Ideograph を除いたもの）

let regexp = /\p{Block=CJK_Symbols_And_Punctuation}/ug;
'一〇〇'.match(regexp);
