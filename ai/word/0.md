------------

文字や文書に関連する英語・日本語の単語・表現は、コンテキスト（データ処理、文書作成、言語学）によって多数存在します。提示された単語以外にも以下のようなものがあります。
 
1. 基礎・構成単位 

    Glyph (グリフ): 文字の具体的な形状・デザイン
    Symbol (シンボル): 記号、文字以外の符号
    Alphabet (アルファベット): 文字列、文字のセット
    Character Code (文字コード): 文字を数値に対応させたもの
    Unicode: 文字符号化方式
    Grapheme (グラフリミ): 意味を持つ最小の文字単位 

2. 文字列・データ処理 (コンピュータ・プログラミング)

    Text Data (テキストデータ): 構造化されていない文字列
    Unstructured Text (非構造化テキスト): フリーフォーマットのテキスト
    String Literal (文字列リテラル): プログラム内で直接記述された文字
    Substring (部分文字列): 文字列の一部
    Charset / Character Set (文字集合): 利用可能な文字のセット
    Blank / Space (空白・スペース): 文字数カウントに含まれる要素
    Delimiter (デリミタ): 区切り文字（カンマ、タブなど） 

3. 文章・構成要素 (自然言語処理・文書)

    Phrase (フレーズ): 語句、フレーズ
    Word (単語): 語
    Sentence (文章): 文
    Paragraph (段落): パラグラフ
    Corpus (コーパス): 言語研究のための構造化された大規模なテキストデータ
    Token (トークン): 自然言語処理における解析単位
    Body (本文): テキストのメイン部分 

4. ドキュメント・文書種類

    Manuscript (マニュスクリプト): 原稿
    Documentation (ドキュメンテーション): 文書化された記録
    Transcript (トランスクリプト): 書き起こし、記録
    File format (ファイルフォーマット): .txt, .doc, .csv など
    Record (レコード): 記録 

5. 日本語の関連用語

    文字列（もじれつ）
    テキスト
    文（ぶん）/ 文章（ぶんしょう）
    字形（じけい）
    字体（じたい）
    書体（しょたい）
    表記（ひょうき） 

これらは、例えば、プログラミングでは string, char がよく使われ、文章解析では corpus, token が重要になるなど、目的によって使い分けられます。

------------
「文字」に関連する単語は、その性質や使われる文脈（文法、IT、デザインなど）によって多岐にわたります。
 
挙げられたもの以外の主要な単語を、カテゴリ別に整理しました。 
1. 「文字」そのものを表す単語

    Word: 単語。複数の文字が集まって意味をなす最小単位。
    Symbol: 記号。文字だけでなく、@や#などの特殊記号も含む。
    Digit: 数字。0から9までの個々の文字。
    Glyph: 字形。フォントなどのデザイン上の具体的な「形」を指す。
    Alphabet: 音素文字の体系。英語では26文字の集合を指す。 

2. 文書・テキストの構成単位

    Sentence: 文。ピリオドで終わる一連の言葉。
    Paragraph: 段落。改行で区切られた文章の塊。
    Line: 行。1行の文字列。
    Passage: 一節。文章や本の中から抜き出した一部分。
    Draft: 草稿。完成前の下書き状態の文書。 

3. IT・プログラミングの文脈

    Script: 台本、あるいは記述言語。また、特定の文字体系（Latin scriptなど）を指すこともある。
    Encoding: エンコード。文字をコンピュータが扱えるコードに変換する方式（UTF-8など）。
    Field: 入力欄。名前や住所などを入力するテキストエリア。
    Content: コンテンツ。文書の中身や内容そのもの。 

4. フォント・表記の文脈

    Font / Typeface: 書体。文字のデザイン。
    Uppercase / Lowercase: 大文字 / 小文字。
    Italic / Bold: 斜体 / 太字。
    Punctuation: 句読点。ピリオドやカンマ、疑問符などの総称。 

さらに、文字の種類を具体的に示す Kanji (漢字) や Pinyin (ピンイン) などの表現もあります。
特定の利用シーン（プログラミングのコード内、デザイン制作、公的な文書作成など）に合わせて、最適な単語を絞り込むお手伝いが必要ですか？

charactorとletterはどちらも文字という意味で使われる。何が違う？
また、stringとtextはどちらも文字列という意味で使われる。何が違う？

用語|意味
----|----
charactor|文字全般
letter|アルファベットのみ対象

用語|意味
----|----
string|コンピュータが処理する文字の羅列
text| 人間が読んで理解できる「意味を持った文章や内容」

観点|概要
----|----
機械可読性|LFやTABなど機械的に読み取りやすい構造化テキストである
人間可読性|自動折返しや単語単位改行など人間が読みやすい構造化テキストである

以下のように複雑化していく。機械可読性、人間可読性を考慮した形式がそれぞれにある。

1. 一次元：文字セット（制御コード一切なし）のバイナリ配列のみ
2. 一次元配列：1を複数に分割する制御コードを加える（SP）英語などの自然言語の一文や関数引数
3. 一次元配列：1を複数に分割する制御コードを加える（SP,HD）
3. 二次元：文字セット＋制御コード(SP,HD,VD)のバイナリ配列。行数と列数で範囲指定可能。
4. 二次元：テキスト：3に加え、行末の単語が途中で分断されず単語の先頭から開始する等の人間可視性を備える
5. 二次元配列：テキスト：4に加えて、複数テキストを単一ページとして管理する制御コードを含める
6. 三次元：テキスト：5に加えて、文書構造を木構造で示す制御コードを含める
7. 三次元配列：テキスト：ディレクトリ構造化し、複数のファイルを一つのファイル内に定義できる
