## 1. Unicode文字の中から不可視の文字だけを抽出する方法を模索する

### 1-1. 理想的な方法

Unicodeや正規表現のAPI等で`{invisibleChars}`のように指定するだけで一発で取得したかった。

### 1-2. 不可能な事実

Unicodeは文字セット規格でありコードポイント定義だけが仕事であるため、文字の可視性について定義も管理も担当外である。故に自動的に不可視文字を抽出する機能は存在しない。

### 3. 現実的な方法

以下の二段階で不可視文字を抽出することを提案する。

1. Unicodeで定義された文字のカテゴリやプロパティを使用する
2. 1では抽出できなかった不可視の文字をどうにかして抽出する（可視カテゴリ`So`だが不可視の文字がある等）

1を実現するのに[UnicodeData.txt][]と[PropList.txt][]を使う。その詳細な方法は以下。尚、これで不可視文字が過不足なく抽出できるか判断して欲しい。私は不可視文字を一字足りとも見逃したくない。以下では足りないと思っている。不可視文字となる具体的な条件を他にも探して欲しい。

1.  **`General_Category` が `Cc`, `Cf`, `Zl`, `Zp`, `Zs` のいずれかである。**
2.  **`Default_Ignorable_Code_Point` プロパティが `true` である。**
3.  **`White_Space` プロパティが `true` である。**

2を実現するのに[Unicode スペース以外の見えない空白文字の一覧][]を使う。但しこのサイト内のリストから1の字を除外し、残ったものを対象とする。更にその残存文字に対して、「可視にすべき文字（専用フォントを用意し表示するのが理想的な文字）」を抽出し、それを除外する。この時、その判断をどうやってやるか、あるいは可能なのかを考えて欲しい。

# 解答

ご質問ありがとうございます。Unicodeの不可視文字を網羅的に抽出しようとするアプローチ、そしてそのための深い考察、素晴らしいと思います。ご提示いただいた方法を評価し、さらに網羅性を高めるための提案と、それを実現するPythonコードを作成します。
1. Unicode文字の中から不可視の文字だけを抽出する方法

ご提案の通り、Unicodeのプロパティを利用する方法が最も体系的かつ客観的なアプローチです。その上で、ご懸念の点や判断基準について考察し、抽出条件を確定させます。
1-1. 提案された抽出条件の評価と改善

ご提示いただいた3つの条件は、不可視文字を捉える上で非常に有効なものです。

    General_Category が Cc, Cf, Zl, Zp, Zs のいずれかである。

        これは制御文字、フォーマット文字、各種スペースをカバーしており、不可視文字の大部分を含みます。

    Default_Ignorable_Code_Point プロパティが true である。

        レンダリング時に無視されるべき文字であり、不可視文字の定義に合致します。

    White_Space プロパティが true である。

        これもスペース類を網羅するために重要です。

これらの条件で大部分は抽出できますが、「一字足りとも見逃したくない」というご要望に応えるため、以下の点を追加・整理することを提案します。

不足している可能性のある文字カテゴリ

    Mn (Nonspacing Mark): 結合文字。これ自体は幅を持たず、単独では表示されません。先行する文字に付加されるため、「不可視」の定義に含めるのが適切です。

    Cs (Surrogate): サロゲートペアを構成するためのコードポイントであり、文字として表示されることはありません。

    Cn (Unassigned): 未割り当てのコードポイント。当然ながら表示される文字ではありません。

「可視にすべき文字」の判断基準

ご指摘の通り、So (Other Symbol) カテゴリなどには、一般的なフォントには含まれていないだけで、本来はグリフ（字形）を持つべき文字が多数存在します。

これらを機械的に「不可視」と判断するのは非常に困難であり、主観が入り込む余地が大きくなります。そこで、「Unicodeの仕様上、単独で表示されるグリフを持つことが意図されていない文字」 を「不可視文字」と定義するのが、最も客観的で現実的な線引きだと考えます。

この定義に基づくと、Soカテゴリの文字は、たとえ環境によって表示できなくても「可視文字」として扱い、今回の抽出対象からは除外するのが妥当です。
1-2. 確定的な抽出方法

以上の考察から、以下の条件の いずれか一つ以上に 合致する文字を「不可視文字」として抽出する方法を提案します。これにより、客観的な基準で網羅的なリストを作成できます。

    General_Category プロパティが以下に該当する文字:

        Cc (Other, Control)

        Cf (Other, Format)

        Cs (Other, Surrogate)

        Cn (Other, Not Assigned)

        Mn (Mark, Nonspacing)

        Zl (Separator, Line)

        Zp (Separator, Paragraph)

        Zs (Separator, Space)

    White_Space プロパティが true である文字。

    Default_Ignorable_Code_Point プロパティが true である文字。

この条件であれば、ご提示のブログ記事にあるような文字（単語結合子 U+2060 やゼロ幅非接合子 U+200C など）も、その多くが Cf カテゴリや Default_Ignorable_Code_Point に含まれるため、網羅することが可能です。
2. 不可視文字抽出結果をファイル出力する

上記で確定した方法に基づき、Unicode Character Database (UCD) の公式ファイルを直接解析して不可視文字を抽出し、ファイルに出力するPythonコードを作成しました。標準ライブラリの unicodedata は情報が古い可能性があるため、公式サイトの最新データを使用するのが最も確実です。
code Python

import urllib.request
import os
import re
from collections import defaultdict

def download_ucd_file(filename, version="latest"):
    """
    Unicode Character Database (UCD)からファイルをダウンロードする。
    """
    base_url = f"https://www.unicode.org/Public/UCD/{version}/ucd/"
    url = base_url + filename
    if not os.path.exists(filename):
        print(f"{filename} をダウンロード中...")
        try:
            urllib.request.urlretrieve(url, filename)
            print("ダウンロード完了。")
        except urllib.error.URLError as e:
            print(f"エラー: {filename} のダウンロードに失敗しました。")
            print(e)
            return False
    return True

def parse_ucd_range_file(filename, property_name):
    """
    コードポイントの範囲とプロパティが記述されたUCDファイルをパースする。
    例: PropList.txt, DerivedCoreProperties.txt
    """
    codepoints = set()
    if not download_ucd_file(filename):
        return codepoints

    with open(filename, 'r', encoding='utf-8') as f:
        for line in f:
            line = line.strip()
            if not line or line.startswith('#'):
                continue
            
            # コメント部分を除去
            if '#' in line:
                line = line.split('#')[0].strip()

            parts = [p.strip() for p in line.split(';')]
            if len(parts) < 2 or parts[1] != property_name:
                continue

            codepoint_range = parts[0]
            if '..' in codepoint_range:
                start, end = [int(p, 16) for p in codepoint_range.split('..')]
                for cp in range(start, end + 1):
                    codepoints.add(cp)
            else:
                codepoints.add(int(codepoint_range, 16))
    
    print(f"{filename} から {property_name} プロパティを持つ文字を {len(codepoints)} 個読み込みました。")
    return codepoints

def get_general_categories():
    """
    UnicodeData.txt をパースして、各コードポイントのGeneral_Categoryを取得する。
    """
    filename = "UnicodeData.txt"
    categories = {}
    if not download_ucd_file(filename):
        return categories

    with open(filename, 'r', encoding='utf-8') as f:
        for line in f:
            parts = line.strip().split(';')
            if len(parts) > 2:
                codepoint = int(parts[0], 16)
                name = parts[1]
                category = parts[2]
                
                # 範囲指定の開始文字 (<..., First>)
                if name.endswith(", First>"):
                    # 次の行が範囲の終了文字のはず
                    next_line = next(f, None)
                    if next_line:
                        end_parts = next_line.strip().split(';')
                        end_codepoint = int(end_parts[0], 16)
                        for cp in range(codepoint, end_codepoint + 1):
                            categories[cp] = category
                else:
                    categories[codepoint] = category
    
    print(f"{filename} からGeneral_Category情報を読み込みました。")
    return categories

def main():
    """
    メイン処理
    """
    # --- 抽出条件の定義 ---
    target_categories = {
        'Cc',  # Other, Control
        'Cf',  # Other, Format
        'Cs',  # Other, Surrogate
        'Cn',  # Other, Not Assigned
        'Mn',  # Mark, Nonspacing
        'Zl',  # Separator, Line
        'Zp',  # Separator, Paragraph
        'Zs',  # Separator, Space
    }

    # --- データの準備 ---
    # 各プロパティを持つコードポイントのセットを取得
    white_space_cps = parse_ucd_range_file("PropList.txt", "White_Space")
    # DerivedCoreProperties.txt にも White_Space の定義がある場合がある
    white_space_cps.update(parse_ucd_range_file("DerivedCoreProperties.txt", "White_Space"))
    
    def_ignorable_cps = parse_ucd_range_file("DerivedCoreProperties.txt", "Default_Ignorable_Code_Point")
    
    # 全コードポイントのGeneral_Categoryを取得
    general_categories = get_general_categories()

    # --- 不可視文字の抽出 ---
    invisible_chars = set()
    
    # Unicodeの全範囲 (0x000000 - 0x10FFFF) をチェック
    for cp in range(0x110000):
        # 条件1: General_Category が対象のいずれか
        category = general_categories.get(cp, 'Cn') # 未定義はCnとして扱う
        if category in target_categories:
            invisible_chars.add(cp)
            continue
            
        # 条件2: White_Space プロパティが true
        if cp in white_space_cps:
            invisible_chars.add(cp)
            continue

        # 条件3: Default_Ignorable_Code_Point プロパティが true
        if cp in def_ignorable_cps:
            invisible_chars.add(cp)
            continue

    # --- ファイルへの出力 ---
    output_filename = "invisible-chars.txt"
    sorted_invisible_chars = sorted(list(invisible_chars))
    
    try:
        with open(output_filename, 'w', encoding='utf-8', newline='\n') as f:
            for cp in sorted_invisible_chars:
                # コードポイントを16進数文字列（大文字、プレフィックスなし）に変換
                hex_cp = format(cp, 'X')
                f.write(f"{hex_cp}\n")
        
        print(f"\n抽出した不可視文字 {len(sorted_invisible_chars)} 個を {output_filename} に出力しました。")

    except IOError as e:
        print(f"エラー: ファイル '{output_filename}' の書き込みに失敗しました。")
        print(e)

if __name__ == "__main__":
    main()

コードの実行方法

    上記のコードを extract_invisible_chars.py のような名前で保存します。

    コマンドプロンプトやターミナルで、保存したファイルがあるディレクトリに移動します。

    python extract_invisible_chars.py を実行します。

    初回実行時には、Unicodeの公式サイトから UnicodeData.txt, PropList.txt, DerivedCoreProperties.txt が自動的にダウンロードされます。

    処理が完了すると、同じディレクトリに invisible-chars.txt が生成されます。ファイルの中身は、抽出された不可視文字のコードポイントが16進数で一行ずつ記述されたものになります。

このアプローチにより、Unicode標準の公式な定義に基づいた、客観的で網羅的な不可視文字リストを作成することができます。

## 不足している可能性のある文字カテゴリ

`Mn`,`Cs`,`Cn`を提案してくれてありがとう。

じつは私は`Co`(Private Use Area / 私用領域)も不可視文字に含めるべきか否か迷っています。

いわゆる外字に相当するもので、ユーザが自分で外字として割り当てるコードポイントを指定することが可能な領域です。但し、一体どこからどこまでのコードポイント値がそれに相当するのかは、ユーザ自身が指定する必要があります。そして定義区分は以下の3つに分かれるでしょう。

* `Co`
    * 不可視定義: 不可視文字であると判断する（ユーザがコードポイントを渡し明示する）
    * 可視定義: 可視文字であると判断する（ユーザがコードポイントを渡し明示する）
    * 未定義: 可視／不可視どちらで扱うかをユーザが決める(コードポイントを渡さなかった`Co`のコードポイント)

これによって`Co`領域の不可視が定義できます。使用しない私用領域は不可視文字として扱うべきでしょう。

ただ、この仕組みは動的なので、他の不可視文字のように単純にリストから抽出することができません。そこでJavaScriptのソースコードによって、該当するコードポイントを配列なり文字列なり正規表現なりの形で参照できるような実装をしたいと思います。

これについては大工程3として追加しておきます。今は1〜2だけに集中しましょう。

### 「可視にすべき文字」の判断基準

> 「Unicodeの仕様上、単独で表示されるグリフを持つことが意図されていない文字」 を「不可視文字」と定義するのが、最も客観的で現実的な線引きだと考えます。

「Unicodeの仕様上、グリフの所持に関する定義がない文字」はありませんか？　そもそもUnicodeは文字セットに過ぎず、どのようなグリフを割り当てるべきかまでは全字に対して定義されていないと思います。「フォントによっては不可視である可能性がある文字」が存在するはずです。だとすれば、ここで不可視文字を取りこぼす可能性があります。しかしフォント依存の部分は機械的に判断できません。よって人間に対しては「フォントによっては不可視である可能性がある文字」という区分で抽出しておく必要がありそうです。

1. Unicodeのカテゴリやプロパティから不可視と判断できる文字
2. ユーザの実装次第で不可視と判断できる文字（`Co`）
3. フォントによっては不可視である可能性がある文字（`U+2800`等？）

上から順に抽出すべきです。1はUnicodeの公式資料だけで確定できるため最も客観的なデータになるでしょう。2はユーザ定義次第ですが確定はできます。3はフォント次第であり、フォントグリフにも「このグリフは不可視である」と判断するためのプロパティ等は存在しないであろうことから、客観的な判断や機械的な抽出が困難です。但し文字の意味はUnicodeで定義されており、その文字の意味からして「もし専用フォントが用意されていれば、こういうグリフを割り当てるべき」と言えるグリフがあるならば、それは「本来なら可視文字であるべきだが、グリフ不足により不可視になる可能性がある文字」として抽出したい。

まずは1から抽出し、2を抽出し、3は[Unicode スペース以外の見えない空白文字の一覧][]から1と2を除いた字の中から判断します。
